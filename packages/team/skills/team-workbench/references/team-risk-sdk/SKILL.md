# 风控 SDK 与动态脚本

先确认厂商、产品、客户端、SDK/脚本摘要、业务场景、接入配置和目标问题。数美与瑞数仅作为分流示例；每个部署可能采用不同配置与服务端规则。自有接入优先核对厂商提供的 SDK、服务端接口、日志及解码工具，样本缺口再进行逆向。站点、客户端和版本分别建档。

## 数美类 SDK

1. 追踪初始化参数、远端配置、设备字段采集、标识生成/缓存、编码、上传及服务端响应。Web、Android、iOS 的字段与生命周期单独记录。
2. 分别采样首次启动、已有状态、升级、清除数据、重装、网络中断、配置变化及设备信息变化；标明哪些字段稳定、变化、延迟上报或由服务端下发。
3. 对请求按“采集前值、处理后字节、协议字段、服务端结果、业务使用”分层比对。设备 ID 相同、上报成功、业务被接受各自单独验收。
4. 出现解密或签名障碍时，使用自有接入密钥和官方工具核验字段；没有对应接入权限时将字段语义保留为未知。

## 瑞数类动态保护

1. 建立页面、动态脚本、请求、令牌和 Cookie 的同版本关联，保存响应、哈希、加载顺序与缓存条件。动态资源更新立即新建样本版本。
2. 对首次访问、刷新、跳转、异步请求、会话过期和错误恢复分别记录状态变化；区分页面 JS 可见值、网络层结果及服务端业务判定。
3. 比较多次正常客户端执行的字段与时序，定位稳定规则和动态依赖。旧版本的入口、常量、字段和顺序不能直接用于新资源。

## 差异与交付

若固定输入仍不一致，逐层核对序列化、时间、随机量和环境字段；若本地一致但服务端拒绝，交给 [注册协议](../team-registration-protocol/SKILL.md) 检查绑定、过期和状态。交付版本矩阵、字段来源表、生命周期图、请求时间线、原始字节差分、授权环境结果和未证实项。需要具体计算时按需加载 [纯算验收](../team-offline-computation/SKILL.md)，不将其全文与本模块一起默认加载。
