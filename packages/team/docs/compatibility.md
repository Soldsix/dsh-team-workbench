# 兼容矩阵与部署范围

## 概要

兼容性由实际宿主、Node、安装方式和会话载体共同决定。主包精确声明 DSH `0.2.1-rc.2`，不会为绕过校验而放宽版本。主服务、个人模式、模型配置及人设文件不参与本次切换。

## 宿主矩阵

| 组合 | 本版结论 |
| --- | --- |
| 官方 npm DSH 0.2.1-rc.2，Windows，Node 24 | 真实 `.tgz` 安装、浏览器确认、团队执行与恢复验证 |
| 现用定制 0.2.1-rc.2 的公开 API 声明 | 严格类型检查与模块回归；正式服务未部署 |
| Node 22.19 | 独立验证结果见测试报告，不能由 Node 24 结果代替 |
| DSH 0.2.2-rc.1 | 声明检查失败；模型选择、投影、PTC 接口不同，主包拒绝安装 |
| 其他 RC、开发分支、其他团队引擎并存 | 未验证；禁止强行覆盖同一服务或忽略 peer |
| Linux（Ubuntu） | 提供 CI 配置；以发布提交的实际运行结果为准，不能从本机 Windows 结果推断 |
| macOS | 未配置该平台 CI，未实机验证 |

## 模式与配置

插件不包含个人模式定义。测试使用合成的模式标记和原生标准模式，不读取实际人设正文。既有模式的风格由原插件负责；团队岗位和任务约束是附加上下文，不应替换原人设。模式自带 skills 使用原优先级解析。

安装助手仅翻译五个能力提供方的配置 ID，保留原模型与模式行。未修改的原提供方保留为禁用状态以便回滚。第三方团队引擎若已提供 agentTeams，加载会报冲突，不能同时争抢同一团队。

## 会话与插件版本

V1 方案保持手动创建，V2 支持显式自动化和资源键。新字段保存在目标 JSON 文本内；没有提升全局 Session 格式，没有修改已提交的历史世代。新写入需要本版插件解释，不能把较老插件接上新数据后继续写入。

旧安装曾使用宿主不认识的原生 team 事件时，需要相应旧宿主读取或单独迁移方案。便携载体不能反过来让官方读取器自动认识所有旧事件。此次没有处理或覆盖用户真实日志。

## Skills、MCP 与系统工具

技能版本固定于任务选择，正文按需进入上下文。包内专业资料不是外部工具安装凭证；MCP、浏览器与移动设备需部署者提供实际连接。只有注册并且位于成员工具上限中的工具才可调用；团队授权不替代宿主沙箱和服务限制。

PowerShell、Python、Node、curl 使用宿主统一执行与后台作业能力。任意程序无法同时保证仅访问几个白名单路径，所以受限目标应使用原生文件和网络工具，完整执行授权须在具体方案中明确。Windows 专项覆盖中文路径、大小写、目录联接、取消、冲突和容量；未实机验证的设备与 MCP 不标为通过。
