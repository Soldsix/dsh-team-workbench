# 团队工作台 0.5

[English](guide.md)

V1 方案继续手动运行。V2 必须显式填写自动化设置，支持成员 persona/instructions 和独占资源键，并可要求双审规划前置。替换方案使用新的版本化任务编号，旧任务和证据保留在历史；较旧团队包不能继续写入新 V2 工作。

按[安装指南](../../../installation.md)使用可审阅的 profile 助手。迁移到 workbench-* ID 时保留原提供方配置，并保留完整配置块。include 加载器的 `name` 是匹配条件，不能借它在原 ID 下替换提供方名称。

新运行沿用既有便携载体和目标 JSON 文本，不移动、覆盖或删除已提交 Session 世代。旧原生团队事件仍需要能识别它们的宿主，本次升级不会转换个人会话档案。

应用前停止目标宿主，先在隔离环境核对合成会话、模式、模型、技能、工具、孙代理、独立复核和重启。保存旧 profile 与安装包以便回滚，单独保留新增会话；不切换正在执行的任务，不扩大 peer 范围绕过兼容失败。

输入及成果归档从本版起保留任务所用的原始内容。同一长期成员可在后续任务修改同一文件；旧提交从不可变归档验证。没有归档的旧记录仍依赖原文件且不能凭空恢复。交接接受明确依赖链中的合法产物更新，普通缓存复用仍拒绝已变化的原输入。

军师请求修订时，指定复核人可以独立核对并退回，接受仍要求双军师批准。退回通知按执行编号去重，队长必须明确安排下一次尝试；不会自动重跑外部操作。

退休成员的恢复校验保存的有效祖先关系，不要求待命父级驻留，也不触发父级模型调用。已退休祖先仍需要先恢复。
