# Shopee 商品详情与匿名访问

确认国家站、域名、语言、币种、客户端、应用版本及商品样本。使用公开页面、平台开放接口或用户授权样本识别详情数据来源；不同国家站与客户端独立建档。“免登录”按无会话公开访问、游客初始化和受限身份三档实测。

## 字段与协议

1. 从一个有多变体的商品建立基线：商品/店铺标识、标题、图片、说明、分类、SKU、规格选项、展示价格、折扣、库存、配送地区和采集时间。保留原始数值与单位，不在解析阶段丢失币种或地区。
2. 将页面显示、接口响应和规范化记录逐字段对应；检查变体组合的价格、库存与不可售状态，区分缺失字段、空值和区域不可用。抽样选择无变体、下架、限区及促销商品核对解析边界。
3. 在全新会话、游客初始化和授权身份分别请求同一商品，建立字段可见矩阵。记录初始化、Cookie/令牌、签名或挑战、请求时效及后端结果；当前样本没有匿名接口时，明确受限字段而不推断存在通用免登录路径。
4. 单条详情通过后检查分页发现与商品 ID 稳定性，再交给 [批量采集](../team-crawler-pipeline/SKILL.md)。版本或站点变化时先比对响应字段与价格单位，再恢复队列；不能让旧解析器静默写入错价。

## 验收

交付国家站/客户端/版本矩阵、身份与字段矩阵、原始响应及解析样本、SKU 组合校验、币种与更新时间、失败分类和访问等级。匿名访问结论只覆盖实测站点、商品类型和字段；业务读取与数据质量都要通过。
