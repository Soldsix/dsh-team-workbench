# 网络与内网安全

沿用本任务已确认的有效授权；团队交接方法缺失时再补读 [团队工作流程](../team-workflow/SKILL.md)。目标至少包含具体网段/资产、测试身份、排除项、窗口、速率和允许操作；已有明确范围不重复索要，但新发现资产是否属于范围需要核对。

## 任务路径

1. 根据用户资产表、配置、架构和获准观测建立服务、身份、网络分段与管理路径图。区分发现线索、确认资产和授权资产；IP 归属或同一域名后缀不能替代授权。
2. 先用现有日志、配置与低影响观测验证暴露、版本和访问关系。主动工具的目标集合、并发、超时与重试必须明确，禁用无范围递归扩展。
3. 按身份/权限、服务缺陷、分段、配置与凭据管理分支调查；需要组合的路径以证据连接，不把孤立弱点直接汇总为已完成的访问链。
4. 在本地等价环境或明确允许的测试资产验证最小影响。涉及远程执行、账号变化、代理通路或数据读取时使用对应许可和测试数据，记录执行身份、开始/结束状态及可恢复措施。
5. 用最少证据证明影响；接触数据的数量和位置受已确认范围限制，不能因“全面测试”自动扩大为不受限导出。CTF 流程与真实网络分别保存目标和结果。

## 验收

交付资产与授权映射、可重复的漏洞证据、已验证路径、未验证前提和修复优先级。对每个测试副作用核对最终状态，不遗留本任务的临时访问或文件。修复后验证原路径失效及必要业务连通；未触达的网段不标为通过。
