# Scene source and licenses

The 32 first component submissions are retained byte for byte and listed in first-component-sha256.json. The QA-owned scaffold, interfaces and build are separate from those submissions; packaging adds an empty favicon and full dependency license files. Later component versions are in multiround.

This demo contains generated scene code and procedural geometry/canvas labels. It includes no personal DSH modes, personas, conversations, model connection settings, credentials or downloaded image assets. The surrounding project license applies to the demo source. Three.js is MIT licensed; its complete upstream license is included in each app and its built output.

Metrics are local browser samples, not a cross-device benchmark. Detailed inspection changes camera constraints and accelerates animation timestamps for rare-event screenshots; these are disclosed QA operations, not default user controls or wall-clock endurance evidence.
